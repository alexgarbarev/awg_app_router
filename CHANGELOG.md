# Changelog

## v1.0.5 — 2026-11-28

- **Починка «демон устарел» на других macOS** ( Sequoia и т.п.). В v1.0.4
  при правке переподписи случайно пропали строки копирования бинарей —
  установщик не обновлял демон, и флаг «устарел» не исчезал. Копирование
  возвращено; снятие сервиса (`bootout`) теперь выполняется ПЕРЕД перезаписью
  бинарей, чтобы не писать в исполняемый файл живого процесса.
- **Сверка обнов по версии, а не по md5 бинаря.** Разделены версии: версия
  приложения (растёт каждый релиз) и версия демона (растёт только когда
  менялся демон). GUI показывает обе в углу окна (`app 1.0.5 · демон 1.0.5`);
  устаревание — по числовому сравнению с `minDaemonVersion`, а не по байтам
  (поэтому переподпись другой macOS больше не даёт ложного «устарел»).
  UI-only релизы не требуют переустановки рабочего демона.

## v1.0.4 — 2026-11-28

- Установщик: больше **не переподписывает установленные бинари безусловно** —
  только если подпись реально не проходит `codesign --verify`. codesign на
  другой версии macOS (например, Sequoia против той, где собран бандл) пишет
  ad-hoc подпись иначе байт-в-байт → md5 установленного расходился с md5
  бандла → GUI вечно показывал «демон устарел» на чистых установках.

## v1.0.3 — 2026-11-28

- Установщик: автоматически снимает карантин (`com.apple.quarantine`) с бандла
  и всех установленных копий (бинари, LaunchDaemon). Без этого скачанный из
  браузера архив не поднимал демона: `Bootstrap failed: 5: Input/output error` —
  launchd отказался бутстрапить помеченный plist.
- Укрощение рестарт-шторма: структурные рестарты туннеля коалесингуются
  (окно 2 с), bounce- и watchdog-рестарты уходят в экспоненциальный backoff
  (10 с → 5 мин и 5 с → 1 мин), при поднявшемся туннеле backoff сбрасывается.
- Тесты: целевой набор `swift test` — характеризационные тесты конфигурации
  (structural hash, round-trip awg) + тесты backoff/governor. 14 тестов.

## v1.0.2 — 2026-11-28

- GUI: при старте на машине без демона сразу появляется кнопка
  «Установить демон…» — раньше она оставалась «Запустить», потому что
  состояние кнопок обновлялось только после первого ответа демона.
- Установщик: показывает полный текст ошибки `launchctl bootstrap`
  (плюс `launchctl print` и хвост лога демона) вместо молчания в `/dev/null`.
- Установщик: устранена гонка bootout→bootstrap — ждём фактического
  завершения сервиса (до 10 с) перед bootstrap.
- GUI: ошибки osascript/macOS показываются настоящим текстом
  (`NSAppleScriptErrorMessage`), а не заглушкой «нет ответа демона».
- README: актуальная инструкция Gatekeeper (System Settings → Privacy &
  Security → «Open Anyway»).

## v1.0.1 — 2026-11-28

- Установка из скачанного архива: GUI копирует скрипт установки в /tmp и
  исполняет оттуда — в обход App Translocation и блокировок карантина;
  расположение ресурсов передаётся через `AWG_RES`.
- Подтверждение установки: перепроверка живого демона до 8 секунд
  (холодный старт launchd занимает несколько секунд) — раньше одиночный
  2-секундный probe промахивался.

## v1.0.0 — 2026-11-27

- Первый публичный релиз: пер-приложенческий split-tunnel для macOS
  (Apple Silicon). Выбранные приложения и их дочерние процессы идут через
  AmneziaWG-туннель (одно ядро sing-box/amnezia-box, N endpoints),
  остальной трафик — напрямую через роутер.
- Kill switch: «Выключить» = режим тюрьмы (0 подключённых серверов,
  переживает закрытие GUI и перезагрузку), «Выключить полностью» — с
  паролем администратора.
- Root-демон через LaunchDaemon + XPC; GUI не блокируется (дедлайны XPC).
- Импорт серверов из `.conf` (AmneziaWG), выбор сервера каждому приложению,
  горячее переключение без рестарта туннеля.
- Автозапуск: логин-айтем GUI, LaunchDaemon демона, автоподключение
  серверов при старте системы.
